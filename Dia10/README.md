## Conceptos Clave

- TypeScript añade tipos estáticos a JavaScript
- Errores se detectan en compilación, no en ejecución
- Interfaces vs Types: interfaces pueden extenderse, types permiten uniones
- Genéricos: código reutilizable mantiene tipos
- strict mode: máxima seguridad de tipos
