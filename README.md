# 🚀 JavaScript Mastery

> Un camino estructurado para dominar JavaScript — desde cero hasta nivel profesional.

## 📖 Sobre el Proyecto

Este repositorio documenta mi viaje hacia la maestría en JavaScript. Cada concepto, patrón y técnica se aborda de forma práctica con ejercicios reales y proyectos funcionales.

**No es otro tutorial más.** Es un registro de aprendizaje profundo donde cada tema se entiende realmente, no solo se "usa".

```

└── ES6+ Features

Profundizando
├── Closures y scope
├── This y contexto
├── Prototypes y herencia

Patrones Avanzados
├── Patrones de diseño en JS

├── Testing (Jest, Vitest)

Frameworks & Ecosistema
├── Node.js fundamentals
├── NPM y gestión de paquetes
├── Bundlers (Vite, Webpack)
└── Frameworks (React/Next.js)
```

## 🎯 Enfoque

- **Calidad sobre cantidad**: Cada tema se domina antes de avanzar
- **Código real**: Sin "hello world" eternos — proyectos funcionales
- **Entender el "por qué"**: No solo cómo, sino cuándo y por qué usarlo
- **Best practices**: Código que se pueda mantener, no código que "funciona"
